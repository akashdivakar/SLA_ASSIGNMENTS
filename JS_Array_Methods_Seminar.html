📊 Array Methods Master Cheat Sheet

Method What it Does Return Value Mutates Original? Example Syntax
.map() Transforms each element into something new New Array (Same Length) No arr.map(x => x * 2)
.filter() Filters elements based on a condition (`true`/`false`) New Array (Filtered subset) No arr.filter(x => x > 10)
.reduce() Aggregates an entire array into a single accumulated result Single Value (Num, Obj, Array) No arr.reduce((acc, x) => acc + x, 0)
.find() Finds the first item matching a condition Item or undefined No arr.find(u => u.id === 5)
.findIndex() Finds index of first matching item Number Index or -1 No arr.findIndex(u => u.id === 5)
.some() Checks if at least one element matches condition Boolean (true / false) No arr.some(x => x < 0)
.every() Checks if all elements match condition Boolean (true / false) No arr.every(x => x >= 35)
.forEach() Executes a callback function for side effects undefined No arr.forEach(x => console.log(x))
.sort() Sorts array elements using compare function Original Array (Modified) Yes arr.sort((a,b) => a - b)
